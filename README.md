# Shameem Clinic — GitHub Pages

Static, mobile-first clinic website layout inspired by the editorial structure of Citron, but rebuilt without Blogger dependencies.

## Deploy
1. Upload this folder to a GitHub repository.
2. Repository Settings → Pages.
3. Source: Deploy from branch → `main` → `/ (root)`.
4. Save.

## Replace before production
- Doctor photo: replace `.portrait-placeholder` with an actual image.
- Confirm clinic address and phone number.
- Add real appointment workflow.
- Replace sample Health Notes with actual posts.
- Add `favicon.svg`, `robots.txt`, `sitemap.xml`, and `404.html`.
- Add MedicalClinic/Physician JSON-LD after confirming credentials and address.


## Branding
The Shameem Clinic logo is included at `assets/shameem-clinic-logo-transparent.png` and is used in the site header.
